# OfflineBan
SCP: CS plugin

Добавляет новую вкладку в АП, с помощью которой можно банить игрока по ID аккаунта, даже если он не находится в данный момент на сервере. Если игрок не заходил на сервер в течение раунда, то его забанит только по ID аккаунта, а если заходил, то ещё по ID устройства и IP.

Название права для админов - `offban`.
