# OfflineBan (v0.2)
SCP: CS plugin

Добавляет новую вкладку в АП, с помощью которой можно банить игрока по ID аккаунта, даже если он не находится в данный момент на сервере. Если не указаны ID устройства и IP и игрок не заходил на сервер в течение раунда, то его забанит только по ID аккаунта, а если заходил, то ID устройства и IP будут внесены в список банов автоматически.

Название права для админов - `offban`.
